Ordenação de Preços de Produtos de Supermercado

1. Objetivo

Este projeto foi desenvolvido em linguagem C para demonstrar o funcionamento de dois algoritmos de ordenação: Bubble Sort e Quick Sort.

 2. Situação-problema

Em um supermercado, organizar os produtos pelo preço facilita a consulta e a comparação dos valores. Por isso, o programa utiliza uma lista com 10 produtos e apresenta seus preços originais e os resultados após a ordenação crescente.

3. Algoritmos utilizados

Bubble Sort

O Bubble Sort compara os preços de produtos vizinhos. Quando o produto atual tem um preço maior que o próximo, os dois trocam de posição. Esse processo se repete até que todos os produtos estejam organizados do menor para o maior preço.

Quick Sort

O Quick Sort escolhe um preço como pivô e reorganiza os produtos em partes menores e maiores que esse valor. Depois, aplica o mesmo processo recursivamente até ordenar toda a lista.

 4. Tecnologias utilizadas

- Linguagem de programação C.
- GitHub para armazenar e compartilhar o código-fonte.

 5. Produtos cadastrados

O programa utiliza os seguintes 10 produtos: arroz, feijão, leite, café, açúcar, óleo, macarrão, farinha, biscoito e sal.

6. Como executar

1. Abra o arquivo `main.c` em um compilador de linguagem C.
2. Compile o programa.
3. Execute a aplicação.
4. Confira a lista original e os resultados do Bubble Sort e do Quick Sort.

7. Resultados esperados

O programa apresenta os preços originais e, em seguida, duas listas ordenadas do menor para o maior preço: uma pelo Bubble Sort e outra pelo Quick Sort.

Os dois algoritmos utilizam os mesmos dados e devem produzir a mesma ordem final.

8. Conclusão

O projeto demonstra como os algoritmos Bubble Sort e Quick Sort podem ser utilizados para resolver uma situação prática. Ambos organizam os preços dos produtos em ordem crescente, mas utilizam estratégias diferentes para realizar a ordenação.
